# Testing

The package is built on Laravel's HTTP client, so the entire Adobe flow —
token, upload, submit, poll, download — mocks cleanly with `Http::fake()`. You never
need real credentials to test code that uses the package.

## Faking the Adobe flow

```php
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Storage;

it('compresses a pdf', function () {
    Storage::fake('local');

    Http::fake([
        '*/token'       => Http::response(['access_token' => 'test', 'expires_in' => 3600]),
        '*/assets'      => Http::response(['uploadUri' => 'https://blob.test/upload/1', 'assetID' => 'urn:asset:1']),
        '*/upload/*'    => Http::response('', 200),
        '*/operation/*' => Http::response('', 201, ['Location' => 'https://pdf-services.adobe.io/status/job-1']),
        '*/status/*'    => Http::response([
            'status' => 'done',
            'asset'  => ['downloadUri' => 'https://blob.test/download/1'],
        ]),
        '*/download/*'  => Http::response('%PDF-1.7 generated bytes'),
    ]);

    $process = LaravelAdobePdf::compress(
        \ArielMejiaDev\LaravelAdobePdf\Support\Source::contents('%PDF source', 'in.pdf')
    )->dispatchSync();

    expect($process->isSuccessful())->toBeTrue();
    expect($process->output())->toBe('%PDF-1.7 generated bytes');
});
```

Using `Source::contents(...)` keeps the test off the filesystem entirely.

## Asserting the request Adobe received

```php
Http::assertSent(fn ($request) =>
    str_ends_with($request->url(), '/operation/extractpdf')
    && $request['elementsToExtract'] === ['text', 'tables']
);
```

## Testing dispatch without running the job

Use `Queue::fake()` to assert an operation was queued, without executing it:

```php
use Illuminate\Support\Facades\Queue;
use ArielMejiaDev\LaravelAdobePdf\Jobs\ProcessAdobePdfOperation;

Queue::fake();

$process = LaravelAdobePdf::create('doc.docx')->onQueue('pdfs')->dispatch();

expect($process->status->value)->toBe('pending');

Queue::assertPushed(
    ProcessAdobePdfOperation::class,
    fn ($job) => $job->processId === $process->id && $job->queue === 'pdfs'
);
```

## Simulating failures

Return a `failed` status (or a non-2xx response) to exercise your error handling:

```php
Http::fake([
    '*/token'       => Http::response(['access_token' => 't', 'expires_in' => 3600]),
    '*/assets'      => Http::response(['uploadUri' => 'https://blob.test/upload/1', 'assetID' => 'urn:1']),
    '*/upload/*'    => Http::response('', 200),
    '*/operation/*' => Http::response('', 201, ['Location' => 'https://pdf-services.adobe.io/status/x']),
    '*/status/*'    => Http::response(['status' => 'failed', 'error' => ['code' => 'BAD_PDF', 'message' => 'Corrupt file']]),
]);

$process = LaravelAdobePdf::compress($source)->dispatchSync();

expect($process->hasFailed())->toBeTrue();
expect($process->error['code'])->toBe('BAD_PDF');
```
